# Portal World

A 3D fantasy meadow with a stone circle of six rippling light-pillar portals. Walk into a portal to play its mini game, and every game has a button back to the world.

| Portal | Game | Folder |
|---|---|---|
| 1, pink | Petal Blast | `04-games/game-1/` |
| 2, violet | Potion Sort | `04-games/game-2/` |
| 3, teal | Crystal Guard | `04-games/game-3/` |
| 4, periwinkle | Synapse Dash | `04-games/game-4/` |
| 5, gold | Lantern Runner | `04-games/game-5/` |
| 6, silver | Crystal Merge | `04-games/game-6/` |

## Run it
It's a static site with no build step. Open it through GitHub Pages, or serve the folder locally (for example `python3 -m http.server`) and open `http://localhost:8000/`. Opening the files directly won't load the 3D world, because browsers block JavaScript modules from `file://`.
